Supervisor authors and dispatch evidence are validated; body digests and immutable message facts are checked. Delivery observations can update without changing identity. Queued, host-pending, delivered, unknown and failed delivery have separate labels; delivered does not imply completed work.
- Visible available conversations refresh history. Layout-commit scrolling follows newly committed rows only while already at the bottom; older pages preserve the scroll offset and readers above the bottom receive a latest marker. The browser probe requires the matching reply to intersect the viewport fully before and after composer focus at normal phone/tablet heights; reduced-height coverage requires partial visibility within the intentionally bounded history region.

No worker routing is added. The discovery runtime retains the published foundation shape; it is not substituted for bootstrap availability.
- Discovery allows no context or attachments, so those controls are hidden. Desktop Enter sends; Shift+Enter, composition and key 229 do not. Visible-viewport height, safe-area padding and retained phone exits keep the composer usable.
- `SupervisorWorkCards.tsx` supplies a **standalone typed boundary**, with an editable task-draft subset and explicit Create callback, and confirmed task/graph operation links to `/work/:taskId`. Tests consume the pinned F2 graph request. These cards have no prose parser, request transport or fabricated history association. Conversation wiring awaits the owner contract described below.
