owner using the independently inspected `observationBinding`. Each page binds
project/task/lineage/attempt/generation/full session identity, fixes the initial
node-sequence snapshot, validates the frozen closed DTO and canonical Rust body

content. Tool/turn/question/text/provider-error reports remain source reports;
explicit truncation/gap records remain visible. Historical contribution markers
cannot imply the current accounting head, a complete transcript, provider health,
readiness or execution authority. Available raw-source evidence is labelled as
reported, not verified central byte retention.

Reads are explicit, same-origin, no-store, five-second/256KiB bounded, at most 16
reports/page and 4 pages/64 loaded reports. There is no polling or per-row request.
Refresh begins a fresh query/snapshot and fences old pending pages. Failed refresh
hides older reports; 401/403 clears private inspection even when bootstrap is
offline. Closing details unmounts the ephemeral query. Foreign bindings/snapshots,
source substitution, changed digests, duplicate keys and unsafe numbers refuse.
