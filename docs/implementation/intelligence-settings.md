# Intelligence Settings spreadsheet and Settings tabs

Settings has six accessible tabs: Identity, Display, Intelligence, Connection, Projects and Notifications. The selected section is restorable with `/settings?tab=…`. The old `/settings/intelligence` link redirects to the Intelligence tab; Overview diagnostics selects Connection.

Intelligence is a spreadsheet with Profile, Description, Model, Reasoning effort and per-row Save controls. A provider dropdown above the table changes the model/effort choices for every row. Add row creates a profile in place. Switching provider preserves the other providers’ mappings; switching Settings tabs preserves unsaved Intelligence drafts. The table scrolls inside its labelled region on narrow screens.

Choices come from qualified server configuration. Providers without configured models show a concise explanation and disabled model/effort cells; owners can still save named, deliberately unconfigured rows. Adding a profile does not assign it to agents or project allowlists. Provisioning providers/models remains separate.

Each edited row retains its original profile version. Conflicts preserve the draft, and interrupted responses are reconciled through the operation ID; an explicit retry resends the identical request. Successful receipts update the cached row immediately. Settings affect future launches; running sessions retain their original artifacts. Backend transaction details are in aq-server `docs/implementation/intelligence-settings.md`.
