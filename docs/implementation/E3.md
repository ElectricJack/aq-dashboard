# E3: versioned dashboard release archive

First release: **v0.1.0** (package version 0.1.0). Task smart-falcon-16.6.

## Delivered interfaces

`scripts/bundle-manifest.mjs` emits schema **2**. It retains `api_version: "dashboard-read-1"` and the `files` map of SHA-256/byte lengths, adding:

- `version`: package version.
- `source`: full Git `revision`, `dirty`, `official`. `--official` refuses tracked or untracked changes.
- `toolchain`: actual `node`, `pnpm`, and `lockfile_sha256` of committed pnpm-lock.yaml bytes. Official pnpm must match packageManager.
- `required_api_versions: ["dashboard-read-1"]`.
- `required_capabilities`: sorted bootstrap capability identifiers consumed by the shipped dashboard, including `results.media.read` and `playbooks.inspect`. These express protocol compatibility requirements, not enabled grants for every principal; runtime authorization remains bootstrap-owned.

`scripts/release-archive.mjs dist <output> v0.1.0 ElectricJack/aq-dashboard` requires a clean official manifest for current HEAD, matching package/tag versions and lockfile/compatibility metadata. It verifies all listed file digests and refuses undeclared paths/symlinks before packaging. GNU ustar, sorted paths, epoch timestamps, fixed numeric ownership and modes, and gzip `-n -9` make the archive deterministic for identical input bytes. Changing source provenance intentionally changes the archive.

Assets:

- `aq-dashboard-v0.1.0.tar.gz`
- `aq-dashboard-v0.1.0.tar.gz.sha256`: archive SHA-256 in sha256sum format.
- `aq-dashboard-v0.1.0.tar.gz.release.json`: schema 1, tag/version/source revision, asset URL, `archive_sha256`, `dashboard_digest`, `manifest_schema_version`. `dashboard_digest` is `sha256:<SHA-256 of exact dashboard-manifest.json bytes>`, matching the bootstrap convention. No archive digest is embedded in its own input.

The release workflow runs on `v*` tags with frozen install, lint, typecheck, tests, build, official manifest generation, deterministic packing, and `gh release create --verify-tag`. Contents write permission is scoped to the release job. The GitHub connector lacks release-asset publication operations, so publication uses gh as the task requires.
